# SPEC-004: レシート発行（Receipt）仕様書

## 1. 概要 (Overview)
コンビニエンスストアPOSシステムにおける「レシート発行」機能の仕様を定義する。
SPEC-003（会計・決済処理）完了後、取引内容をレシート形式に整形し、画面プレビュー表示およびプリンタ出力を行う。

---

## 2. 業務要件 (Functional Requirements)

### 2.1 レシートデータ構築（Receipt Data Construction）
会計完了時に、以下の情報を含む `Receipt` オブジェクトを構築する。

#### 2.1.1 店舗情報（Store Information）
- **StoreName**: 店舗名（例: "Convenience POS Store"）
- **StoreAddress**: 店舗住所（例: "東京都渋谷区..."）
- **StorePhone**: 電話番号
- **RegisterNumber**: レジ番号
- **StaffName**: 担当者名

#### 2.1.2 取引情報（Transaction Information）
- **TransactionNumber**: 取引番号（例: `TRX-20260817-123456-123`）
- **TransactionDateTime**: 取引日時（フォーマット: `yyyy年MM月dd日 HH:mm`）

#### 2.1.3 明細情報（Line Items）
各商品明細について：
- 商品名
- 数量
- 単価（税抜）
- 税区分表示（※8% / ※10%）
- 税込小計

#### 2.1.4 金額集計（Tax & Total Summary）
- 税抜合計
- 8%対象額 / 8%消費税額
- 10%対象額 / 10%消費税額
- **税込合計金額**

#### 2.1.5 支払情報（Payment Information）
- 支払方法
- お預かり金額（現金の場合）
- お釣り金額（現金の場合）

### 2.2 レシートテキスト生成（Receipt Text Generation）
`IReceiptService` を通じて、印刷対応のテキスト形式レシートを生成する。

#### レシートレイアウト（Receipt Layout）
```
================================
    Convenience POS Store
  東京都渋谷区...  03-1234-5678
  レジ#01  担当: 鈴木 レジ担当
================================
  取引番号: TRX-20260817-123
  2026年08月17日 14:30
--------------------------------
  おにぎり 鮭        2   ¥260 ※8%
  ファミチキ          1   ¥213 ※8%
  紙コップ 160ml     3   ¥450 ※10%
--------------------------------
  税抜合計               ¥923
  8% 対象: ¥473  消費税: ¥37
  10%対象: ¥450  消費税: ¥45
  消費税合計                 ¥82
==============================
  税込合計              ¥1,005
  [現金] お預かり        ¥2,000
  お釣り                ¥995
================================
  ありがとうお越し下さいました
  またのご来店をお待ちしております
================================
```

#### 書式仕様
- 1行あたり **32文字** 幅（コンビニ一般的なレシート幅）
- 区切り線: `=`（ヘッダ/フッタ）, `-`（セクション区切り）
- 金額: 右寄せフォーマット（`¥xxx`）
- 税区分: 商品名末尾に `※8%` / `※10%` を付記
- 数量: `商品名 数量 ¥小計` 形式

### 2.3 レシート画面プレビュー（Receipt Preview Modal）
会計完了後、「レシートを表示」ボタンまたは自動でレシートプレビューモーダルを表示する。

#### モーダル仕様
- モーダルタイトル: "レシートプレビュー"
- レシートテキストを等幅フォント（Consolas / Courier New）で表示
- ボタン:
  - 「印刷」ボタン: レシートプリンタへの出力
  - 「閉じる」ボタン: モーダルを閉じ、次客待機状態へ遷移
- ESCキーでモーダルを閉じる

### 2.4 レシート印刷（Receipt Printing）
- `PrintDialog` を使用し、システム設定されたプリンタに出力。
- プリンタ未設定時はエラーメッセージを表示し、プレビュー画面は維持。
- 印刷フォーマット: 白背景・黒文字・等幅フォーボット。

### 2.5 会計完了フロー統合（Completion Flow Integration）
1. 会計確定 → 取引完了モーダル表示
2. 「レシートを表示」ボタン押下 → レシートプレビューモーダル表示
3. プレビュー画面で印刷ボタン押下 → プリンタ出力
4. 「閉じる」ボタン押下 → モーダル閉じ・次客リセット

## 3. 非機能要件・アーキテクチャ (Architecture & Technical Constraints)

- **設計パターン**: MVVMパターン（`CommunityToolkit.Mvvm`）に厳格に従う。
- **制約**: **コードビハインド禁止（No Code-Behind）**。
- **Service層**: `IReceiptService` / `ReceiptService` によるレシートデータ構築・テキスト生成ロジックの分離。
- **Model層**: `Receipt` 不変オブジェクト（コンストラクタで全値を確定）。
- **ViewModel層**: `MainViewModel` が `IReceiptService` から `Receipt` を受け取り、プレビュー用テキストを生成。
- **DI**: `App.xaml.cs` にて `IReceiptService` を登録。
- **単体テスト**: `xUnit` による以下のシナリオをカバーすること。
  - `Receipt` オブジェクトの正しい構築
  - レシートテキストが正しい行数・フォーマットで生成されること
  - 金額の右寄せフォーマットが正しいこと
  - 税区分表記が正しいこと
  - 空明細時のレシート生成
