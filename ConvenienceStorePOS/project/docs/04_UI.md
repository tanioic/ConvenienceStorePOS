## モーダル画面（3つ）

### 1. お会計モーダル (SPEC-003)
- 780x680 のオーバーレイ
- ご請求金額バナー
- 支払方法タブ: [現金] [クレジット] [電子マネー] [QR]
- 現金入力: テンキー + クイック金種ボタン（ちょうど/千円/5千円/1万円/+千円/+5千/+1万）
- お釣り表示 + 金種内訳
- キャッシュレス: 決済端末操作ガイド画面
- [戻る (Esc)] [確定 (会計完了)]

### 2. 会計完了モーダル (SPEC-003)
- 600幅のモーダル
- 取引番号、支払方法、合計点数、ご請求金額、お預かり、お釣り + 金種内訳
- [レシートを表示 (F2)] [次の取引へ]

### 3. レシートプレビューモーダル (SPEC-004)
- 500幅のモーダル
- 等幅フォント（Consolas, Courier New）で32文字幅レシートを表示
- [閉じる] [印刷 (F3)]

## キーボードショートカット
| キー | アクション |
|---|---|
| `Enter` | バーコード入力欄で商品登録 |
| `F12` | お会計モーダルを開く |
| `Escape` | モーダルを閉じる |
| `F2` | レシートを表示 |
| `F3` | レシート印刷 |

## カート明細行レイアウト
各 `CartItemViewModel` は5カラム:
1. 商品名 + 税区分バッジ（軽減8% / 標準10%） + JANコード
2. 単価
3. 数量ステッパー（[-] [数量] [+]）
4. 小計（税込）
5. 削除ボタン（✕）

## 商品カードレイアウト
各 `ProductItemViewModel` は148x102のボタン:
1. カテゴリ名（左）+ 税区分バッジ（右）
2. 商品名（中央、折り返し）
3. 税抜価格（小）+ 税込価格（大、PrimaryColor）

## 色彩設計（App.xaml）
| リソースキー | 色 | 用途 |
|---|---|---|
| `PrimaryColor` | #1565C0 | ヘッダ、アクション |
| `AccentColor` | #00897B | 会計ボタン、完了ボタン |
| `ReducedTaxColor` | #2E7D32 | 8%軽減税率バッジ |
| `StandardTaxColor` | #1565C0 | 10%標準税率バッジ |
| `DangerColor` | #C62828 | エラー、取消ボタン |
| `BackgroundColor` | #F4F6F9 | 画面背景 |

## Value Converter
- `CurrencyFormatConverter`: decimal → `"¥xxx"` フォーマット
- `TaxRateBadgeBrushConverter`: TaxRateType → SolidColorBrush（色分け）
- `BooleanToVisibilityConverter`: bool → Visibility（Invertパラメータ対応）

## 商品管理画面 (SPEC-005)
- 左側: 商品一覧DataGrid + 検索・フィルタバー
- 右側: 操作ボタン / 編集フォーム（トグル表示）
- ヘッダー: 「商品管理」ボタン（メイン画面からアクセス）

## 売上集計画面 (SPEC-006)
- ヘッダー: 期間指定エリア（DatePicker + クイック選択 + 集計実行ボタン）
- サマリーパネル: 4つの集計値を横並びで表示
- DataGrid（左）: 日別売上一覧
- DataGrid（右上）: 商品別売上
- DataGrid（右下）: 支払方法別売上
